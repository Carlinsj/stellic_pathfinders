# Competition demo script

Target length: 90–110 seconds.

**0:00 — Promise**  
“When a class changes rooms, RoomReady checks whether the student’s required classroom features moved with it.”

**0:10 — Trigger**  
Launch the simulator. CS-GY 6033 begins in Room 202, where all five of Maya’s functional requirements are supported. Run the competition demo to move it to Room 815.

**0:25 — Detect and explain**  
The workflow immediately evaluates one affected enrolment. Room 815 needs action: it lacks an adjustable desk, step-free instruction access, integrated accessible seating, and an outlet reachable from accessible seating.

**0:45 — Recommend safely**  
Open the comparison. Room 812 is first because it passes all five hard requirements, is available, fits 42 students, stays on the same floor, and is 18 metres away. Room 815 and Room 804 are excluded rather than awarded proximity points.

**1:05 — Coordinate the response**  
Open case RR-1042. Assign it, request verification if desired, then confirm Room 812 and resolve the case. Emphasise that authorised staff—not the software—make the final reassignment.

**1:25 — Preserve privacy**  
Open notifications. The instructor learns only that the assigned room does not satisfy an approved classroom-access requirement. Maya’s name, diagnosis, and complete feature profile are absent.

**1:40 — Reset**  
Use Reset demo to restore the original Room 202 assignment for the next judge.
